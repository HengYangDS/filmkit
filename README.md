# Film Kit

Film Kit rebuilds a narrated explainer film, an edition in each language the film declares, from the film's tracked sources. The engine carries no film's content. The [DDWG introduction films](https://github.com/HengYangDS/data-department-work-guidelines-film) are built with it.

## Where to read

- [The documentation](docs/README.md): what a film provides to the engine and how the engine builds it.
- [The specifications](openspec/specs/): what the engine guarantees; each change is proposed, designed and archived in [`openspec/changes/`](openspec/changes/).
- [The Changelog](CHANGELOG.md): what each release changes and what a film changes to adopt it.
- [CONTRIBUTING.md](CONTRIBUTING.md): how the engine is developed.

## How to start

Install the engine in a film as [Installing the engine in a film](docs/install.md) states, lay the film out and declare it as [A film's layout](docs/film-layout.md) states, then build it as [Building a film](docs/build-a-film.md) states.
