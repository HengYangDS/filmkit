This short film shows how a film is rebuilt from its sources. The script holds what is said, a reference recording sets the narrator's voice, and the composition draws every frame.

The build first narrates the script. It joins the recordings into one soundtrack and times the captions to the speech. Each part is narrated from a fixed seed, so every rebuild produces the same voice.

Then it renders every frame and packages the films. None of these steps reaches the network, and every file they make stays in the build folder.

Last, each film is checked against its sources. The check covers the recordings, the soundtrack, the captions, the picture and the packages, and each must match the inputs it was made from. Only when everything matches is the rebuild complete.
