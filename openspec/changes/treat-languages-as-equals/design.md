## Goals / Non-Goals

**Goals:**

- One source for which languages a film has and their order: the film's declaration.
- One declaration for each language in the engine, and no code that chooses a behaviour by a language's code, name, tag or script.
- Place follows role: each edition's files in the folder of its code, what every edition shares above them, no language unmarked in any name, and no file that repeats what the engine derives.
- A film of one edition or more builds wherever the engine declares its languages.
- A pure move keeps a film's delivered bytes, proven on the sample on one engine.

**Non-Goals.** Five are follow-ups of their own (session decision 10), each landing in a later release of the derivation [S8, §5.5]; the engine's maintainer owns each, and each is reviewed on 30 November 2026:

- **Picture words by id, one table per edition (Change B, the derivation's R5; audit fault 1).** The films' pictures hold each edition's words inline: 1,319 `L(zh, english)` calls and 243 switches in 136 of 238 picture modules, and 57 calls and 2 switches in the sample; `L` gives the Chinese words to every edition that is not `en`. Labels that repeat the narration would take their words from the anchors of 0.30.0, and the rest from a table in each edition's folder, so that the picture holds no language's words. It touches every picture module of every film, each in its own lane, while this Change touches none; its next action is a draft written after this Change lands, sample first.
- **The README's form (the documentation goal G-2, R2b; audit fault 7).** At 147 KB the README restates the specifications and the code's constants; the owner wants it a thin entry that points the way. Its form waits for ETHOS's design file. This Change replaces only the README's statements that it would make false and adds no section, so the README is no larger after it; the new behaviour is stated in the specifications, the Changelog and the modules' docstrings.
- **The tracked generated bundle `picture/film.js` (R5; audit fault 4).** Each film tracks the bundle that `picture/bundle.mjs` generates from `picture/film/`, and a test holds the two equal, which the owner's rule of 20 November 2026 says is no source. It concerns how a film's picture is built, not languages; the next action is a draft that lets staging build or read the composition from its sources.
- **The keying of evidence and caches (R2b; audit fault 9).** Evidence is keyed by code in a folder, by code in three positions of a file name and, for the alignment and transcript caches, by the language's English name. This Change derives those names from the language declaration without moving them, so no record moves twice; the next action is a draft that keys every cache and plan by code below `build/evidence/editions/<code>/`.
- **The release record's place (R2b; audit fault 12).** `content/release.json` sits among the sources it records. Moving it changes every film's release commands and the reproduction check, which concern no language; the next action is a draft that gives the record its own place.

Also outside this Change: `produce --language all` (decision 12); a third language (the engine declares Chinese and English; a third is a declaration and any kind of behaviour it needs that the engine lacks); the player style's font list, which names a CJK face for every page because any page may show a Chinese title; rebuilding a released edition.

## Risks / Trade-offs

- [Every take of a film that adopts binds a new pronunciation digest] → Its fingerprint and its recording's file name change, so a film's `narrate` task would narrate every take again. `select` binds a take's spoken text and its reference's content, not the contract's digest (`selection.py:138-146`), and task 7.4 holds a take recorded under the whole contract selected after the split; a film keeps its takes by running `select` and what follows, not `narrate`. The December lanes narrating on 0.29.0 now keep their takes in the same way.
- [The union of the classes counts a character that a site did not count before] → Only characters of CJK Extension A, the compatibility ideographs, the full-width forms or the closing marks one set lacked could change a result. Task 2.3 scans the sample's and the films' tracked texts and runs the checks a find would change.
- [Two fresh narrations of one request might differ] → Task 1.4 builds from an empty `build/` both times, since the base engine's selection refuses the first build's Chinese takes after their reference moved (decision 11), and wherever any stage differs it adds a build of the base without the move, which tells the build's own variation from the move's effect.
- [Three to five heavy builds of the sample] → Each runs as the child of a host ticket. Their time is unmeasured; the durations task reports each.
- [No film exercises the picture checks that decision 5 changes, since the sample's labels are few] → Task 10.4 runs `check-picture` on one film's scratch copy before and after, and records each difference with its cause.
- [A third language may need a kind the engine lacks] → The loader refuses a declaration that names a kind the engine does not hold, naming it.
- [The Node audits read the classes from the engine's package] → `scripts.mjs` resolves the data file beside itself; a Node test reads it in place, and the wheel holds it.
- [The loader reads `sources`, a withdrawn key] → It reads it only to find files not yet moved, and refuses it in the same refusal; no other step reads it.
- [The prompts' policy lines change their form] → They are review inputs, not delivered files; the next round's prompts read differently.
- [The December trial copies hold the only copy of their edits] → The films session commits them in each December lane before moving, so the move is one `git mv` commit [S2, §5.7].
- [A film keeps a withdrawn key] → The engine refuses at load with one line that says what to do, and the `declaration` question lists it.
- [A bridge outlives its release] → Each bridge's task names the release that deletes it (R2b for the verifier's and the release record's loops and for the `editions` question, R6 for `delivery/entry.py`), and that release's Change lists it.
- [The loader reads every source at each load] → It reads the scripts, casts, parts and two text files that a film holds, kilobytes in all, and stops at no first problem; its cost is unmeasured and is measured by task 10.1's suite.
