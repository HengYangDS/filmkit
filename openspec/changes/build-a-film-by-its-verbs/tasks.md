Every task leaves the engine's whole suite passing on its commit, the suite run as the child of a host ticket, since the host's rules count it heavy. The tests each task names are light, run at `nice -n 15` in under two minutes, unless the task is marked **heavy**. The sample film goes first; no task changes a film's own checkout, and no task changes a delivered byte.
